# Selamat Datang di QashierWise

**QashierWise** adalah platform **Chatbot WhatsApp berbasis AI** plus sistem **Point of Sale (POS)**, **Reservasi**, **Delivery**, dan **Pembayaran QRIS** — dirancang khusus untuk restoran dan UMKM di Indonesia.

Semua dikelola dari satu layar admin yang kami sebut **Console**: Inbox pesan, Pesanan, Reservasi, Menu/Katalog, hingga laporan penjualan.

> Pelanggan cukup chat lewat WhatsApp — tanpa aplikasi baru. Staf Anda cukup membuka satu dashboard berbasis web.

---

## Apa yang bisa Anda lakukan?

| Fitur | Ringkasan |
| --- | --- |
| **WhatsApp Business** | Hubungkan nomor WhatsApp resmi (WABA) lewat Embedded Signup, balas chat, kelola kontak & template pesan. |
| **AI Agent** | Chatbot AI yang menjawab pertanyaan menu, jam buka, reservasi, dan menerima pesanan secara otomatis 24/7. |
| **Katalog Produk** | Sinkronkan menu ke Meta Catalog agar bisa dikirim sebagai pesan katalog interaktif di WhatsApp. |
| **POS Kasir** | Kelola produk, kategori, meja, pesanan, transaksi, dan laporan penjualan. |
| **Reservasi** | Terima reservasi meja via form publik & WhatsApp, lengkap dengan kalender dan pengingat otomatis. |
| **Delivery** | Atur ongkir, antrean driver, dan bukti pengiriman (foto + lokasi GPS). |
| **Pembayaran** | Terima pembayaran QRIS otomatis, kelola saldo, dan tarik dana ke rekening bank. |
| **CRM** | Tandai pelanggan dengan tag untuk segmentasi & follow-up. |

---

## Alur kerja inti

1. **Pelanggan chat** ke nomor WhatsApp restoran Anda.
2. **AI Agent merespons otomatis** — menu, jam buka, reservasi, hingga membuat pesanan.
3. **Invoice QRIS dikirim** otomatis; status pembayaran terdeteksi instan.
4. **Anda pantau semuanya** dari Console: pesanan, reservasi, dan laporan.
