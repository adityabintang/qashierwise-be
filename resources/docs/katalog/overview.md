# Katalog — Pengenalan

**Katalog** adalah daftar produk/menu Anda yang disimpan di **Meta Commerce Manager** dan terhubung ke WhatsApp Business. Dengan katalog, AI Agent bisa mengirim **pesan katalog interaktif** (multi-product message) — pelanggan melihat foto, harga, dan deskripsi, lalu memilih langsung di chat.

Buka menu **Meta Catalog** di dashboard.

## Katalog vs. Produk POS

QashierWise punya dua tempat "produk", dengan tujuan berbeda:

| | **Katalog (Meta)** | **Produk POS** |
| --- | --- | --- |
| Disimpan di | Meta Commerce Manager | Database QashierWise |
| Tujuan | Ditampilkan ke pelanggan di WhatsApp | Kasir, pesanan, laporan internal |
| Lihat | Menu ini | **[POS → Produk](/docs/pos/produk)** |

Untuk pengalaman terbaik, jaga keduanya tetap sinkron.

## Prasyarat

- **WhatsApp terhubung.** Jika belum, halaman menampilkan **"WhatsApp Belum Terhubung"**.
- Fitur katalog di-aktifkan. Bila sedang dalam peninjauan, Anda melihat **"Fitur Katalog Sedang Ditinjau"** — ini terkait status review aplikasi di Meta.
