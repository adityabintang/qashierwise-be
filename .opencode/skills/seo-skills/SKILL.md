# SEO Checklist for Website Analysis and Gap Identification

## How to Use This Checklist
This checklist is designed to be used with AI tools for comprehensive SEO audits. For each section, you can:
1. Document your website's current status (✓, ✗, or Partial)
2. Use the findings to prompt AI for analysis of gaps
3. Request AI assistance for specific improvements

---

## 1. TECHNICAL SEO

### 1.1 Site Structure & Architecture
- [ ] Website has a clear, logical hierarchy
- [ ] URL structure is clean and descriptive (e.g., /category/subcategory/page)
- [ ] Maximum 3 clicks from homepage to any page
- [ ] Breadcrumb navigation is implemented
- [ ] XML sitemap exists and is submitted to search engines
- [ ] robots.txt file is optimized
- [ ] No duplicate content issues exist
- [ ] Proper canonicalization is implemented
- [ ] Internal linking strategy is comprehensive

### 1.2 Site Performance
- [ ] Page load time is under 3 seconds (desktop)
- [ ] Page load time is under 5 seconds (mobile)
- [ ] Core Web Vitals are optimized
  - [ ] Largest Contentful Paint (LCP) < 2.5 seconds
  - [ ] First Input Delay (FID) < 100 milliseconds
  - [ ] Cumulative Layout Shift (CLS) < 0.1
- [ ] Images are optimized and compressed
- [ ] CSS and JavaScript are minified
- [ ] Lazy loading is implemented for images
- [ ] Caching strategy is in place
- [ ] CDN is used for content delivery

### 1.3 Mobile Optimization
- [ ] Website is mobile-responsive
- [ ] Mobile-first indexing is implemented
- [ ] Viewport meta tag is properly configured
- [ ] Touch buttons are appropriately sized (minimum 48x48px)
- [ ] Text is readable without zooming on mobile
- [ ] Mobile navigation is user-friendly
- [ ] Mobile page speed is optimized

### 1.4 HTTPS & Security
- [ ] Website uses HTTPS protocol (SSL/TLS certificate)
- [ ] Mixed content issues are resolved
- [ ] Security headers are implemented
- [ ] No security warnings appear in browser

### 1.5 Indexing & Crawlability
- [ ] Website is indexed in Google Search Console
- [ ] Website is indexed in Bing Webmaster Tools
- [ ] No crawl errors in Search Console
- [ ] robots.txt allows search engine crawling
- [ ] No noindex tags on indexable pages
- [ ] JavaScript rendering is not blocking crawling
- [ ] Crawl budget is optimized

---

## 2. ON-PAGE SEO

### 2.1 Title Tags & Meta Descriptions
- [ ] Every page has a unique title tag (50-60 characters)
- [ ] Title tags include primary keyword
- [ ] Every page has a unique meta description (150-160 characters)
- [ ] Meta descriptions are compelling and include CTA
- [ ] Meta descriptions include relevant keywords

### 2.2 Heading Tags (H1-H6)
- [ ] Every page has exactly one H1 tag
- [ ] H1 tag includes primary keyword
- [ ] Heading hierarchy is logical (H1 → H2 → H3)
- [ ] All headings are descriptive and unique
- [ ] No skipped heading levels

### 2.3 Content Quality & Optimization
- [ ] Primary keyword appears in first 100 words
- [ ] Primary keyword density is 1-2%
- [ ] LSI keywords (synonyms) are naturally incorporated
- [ ] Content is original and valuable (no plagiarism)
- [ ] Content is comprehensive and in-depth
- [ ] Paragraph length is appropriate (2-3 sentences)
- [ ] Sentences are concise and readable
- [ ] Content uses active voice predominantly

### 2.4 URL Optimization
- [ ] URLs are clean, descriptive, and short
- [ ] URLs contain primary keyword
- [ ] No date-based URLs (unless necessary)
- [ ] Underscores are not used (use hyphens instead)
- [ ] URLs use lowercase letters
- [ ] URLs are easily memorable

### 2.5 Internal Linking
- [ ] Anchor text is descriptive and keyword-rich
- [ ] Internal links point to relevant pages
- [ ] Orphaned pages (with no internal links) don't exist
- [ ] Link depth from homepage is minimal
- [ ] No excessive internal linking (>100 per page)
- [ ] Deep linking strategy supports crawlability

### 2.6 Keyword Usage
- [ ] Keyword research has been conducted
- [ ] Primary and secondary keywords are identified
- [ ] Keywords are naturally integrated
- [ ] Long-tail keywords are targeted
- [ ] Keyword cannibalization doesn't exist
- [ ] User intent aligns with keyword targeting

### 2.7 Content Formatting
- [ ] Content uses bullet points and lists for readability
- [ ] Bold and italics highlight important terms
- [ ] White space is used effectively
- [ ] Paragraphs are short and scannable
- [ ] Content is easy to skim
- [ ] Content includes relevant statistics and data

## 3. TECHNICAL CONTENT OPTIMIZATION

### 3.1 Images
- [ ] All images have descriptive alt text
- [ ] Image filenames are SEO-friendly
- [ ] Images are optimized for size and format
- [ ] Image dimensions are specified (width/height)
- [ ] Responsive images are served
- [ ] No images contain critical text (or text is also in HTML)
- [ ] Image sitemaps are submitted (if applicable)

### 3.2 Video & Multimedia
- [ ] Videos have descriptive titles and descriptions
- [ ] Video transcripts are provided
- [ ] Video schema markup is implemented
- [ ] Video sitemaps are submitted (if applicable)
- [ ] Multimedia content includes meta information

### 3.3 Schema Markup & Structured Data
- [ ] Schema.org markup is implemented
- [ ] Organization schema is present
- [ ] Product schema (if applicable)
- [ ] Review/Rating schema (if applicable)
- [ ] Local business schema (if applicable)
- [ ] Article schema (if applicable)
- [ ] BreadcrumbList schema is implemented
- [ ] FAQPage schema (if applicable)
- [ ] Structured data is valid (tested in Schema validator)

## 4. OFF-PAGE SEO

### 4.1 Backlinks & Link Profile
- [ ] Website has quality backlinks from authoritative sites
- [ ] Backlinks are from relevant industry sources
- [ ] No suspicious or low-quality backlinks exist
- [ ] Anchor text is natural and varied
- [ ] No excessive exact-match anchor text
- [ ] No private blog network (PBN) links
- [ ] Link velocity is natural (gradual growth)
- [ ] No sudden link drops or unnatural patterns

### 4.2 Link Building
- [ ] Link building strategy is documented
- [ ] Guest posting is conducted on relevant sites
- [ ] Directory listings are verified (if appropriate)
- [ ] Local citations are complete (if applicable)
- [ ] Press releases are distributed appropriately
- [ ] Broken link building is implemented
- [ ] Competitor backlinks are analyzed

### 4.3 Social Signals
- [ ] Social media profiles are optimized
- [ ] Content is regularly shared on social platforms
- [ ] Social engagement rate is monitored
- [ ] Social media bios include website link
- [ ] Consistent branding across social platforms

### 4.4 Brand Signals & Authority
- [ ] Brand mentions are tracked (branded and unbranded)
- [ ] Brand is mentioned in industry publications
- [ ] Author authority is established (if applicable)
- [ ] E-A-T signals are strong (Expertise, Authoritativeness, Trustworthiness)
- [ ] Reviews and ratings are positive

## How to Use This Checklist with AI

**Prompt Template for AI Analysis:**

"I have an SEO checklist for my website. Please analyze the following items from my checklist:
- [List items marked as ✗ or Partial]

For each item marked as incomplete, please:
1. Explain why it's important for SEO
2. Identify the specific gap in my current implementation
3. Provide 3-5 actionable steps to improve
4. Estimate the effort required (quick win, medium, or long-term)
5. Identify any tools that would help

Please prioritize recommendations based on potential SEO impact."

## Quick Reference: Priority Areas by Impact

**Quick Wins (High Impact, Low Effort):**
- Title tags and meta descriptions
- Primary keyword in H1
- Image alt text
- Mobile responsiveness verification
- Google Business Profile optimization (local)

**Medium Effort, High Impact:**
- Schema markup implementation
- Internal linking optimization
- Content gap analysis and creation
- Backlink gap analysis
- Core Web Vitals optimization

**Long-term Strategic (Ongoing):**
- Content strategy and creation
- Link building program
- Competitive analysis
- Brand authority building
- Regular monitoring and updates
