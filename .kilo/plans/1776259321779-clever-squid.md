# Plan: Reliable Menu Pagination for AI Agent

## Goal
Implement deterministic, reliable pagination for the "ada menu yang lainnya" flow in WhatsApp AI Agent. Instead of relying on the LLM to guess the next page number, the system will track the current menu page in conversation state and auto-increment when the user asks for more.

public function getCurrentMenuPage(): int
{
    return $this->order_context['current_menu_page'] ?? 1;
}

public function setCurrentMenuPage(int $page): void
{
    $orderContext = $this->order_context ?? [];
    $orderContext['current_menu_page'] = $page;
    $this->order_context = $orderContext;
    $this->save();
}

public function clearCurrentMenuPage(): void
{
    $orderContext = $this->order_context ?? [];

    $this->order_context = $orderContext;
    $this->save();
}

```php
public function isNextMenuPageIntent(string $messageText): bool
{
    $text = strtolower(trim($messageText));
    $keywords = [
        'menu lainnya', 'menu selanjutnya', 'menu berikutnya',
        'menu lagi', 'lihat lagi', 'lihat selanjutnya',
        'masih ada lagi', 'masih ada yang lain',
        'ada lagi', 'ada yang lain', 'lainnya',
        'lebih banyak', 'selanjutnya', 'next menu',
        'page berikutnya', 'halaman berikutnya',
    ];

    foreach ($keywords as $keyword) {
        if (str_contains($text, $keyword)) {
            return true;
        }
    }

    return false;
}
```

#### 3c. Add `handleNextMenuPage()` method

This method handles the pagination bypass — directly calls `getAllProducts()` with incremented page and sends the result without involving LLM:

```php
protected function handleNextMenuPage(
    AiAgentConversation $conversation,
    WhatsAppAccount $account,
    WhatsAppContact $contact,
    AiAgent $aiAgent
): void {
    $currentPage = $conversation->getCurrentMenuPage();
    $nextPage = $currentPage + 1;
    $useToon = $aiAgent->use_toon_format ?? false;

    $result = $this->getAllProducts($account->user_id, $useToon, $nextPage);

    // Check if empty (no more products)
    if (str_starts_with($result, 'EMPTY')) {
        $conversation->addMessage('ai', 'Sudah tidak ada menu lagi. Itu semua menu yang tersedia! 😊 Mau pesan yang mana?');
        $this->sendReply($account, $contact->wa_id, 'Sudah tidak ada menu lagi. Itu semua menu yang tersedia! 😊 Mau pesan yang mana?');
        return;
    }

    // Update tracked page
    $conversation->setCurrentMenuPage($nextPage);

    // Add user message to conversation history
    $conversation->addMessage('human', 'menu lainnya');

    // Pass result to LLM for friendly formatting
    $systemPrompt = $aiAgent->buildSystemPrompt($account->user_id);
    $messages = $conversation->getRecentMessages(2);
    $messages[] = ['role' => 'user', 'content' => "Berikut adalah menu halaman {$nextPage} yang perlu ditampilkan ke user dalam format yang ramah:\n\n{$result}"];

    $tools = $this->getToolDefinitionsForAgent($aiAgent);
    $response = $this->callLLM($systemPrompt, $messages, null, $aiAgent);
    $assistantMessage = $response['content'] ?? '';

    if (empty(trim($assistantMessage))) {
        $assistantMessage = $this->formatMenuFallback($result, $nextPage);
    }

    $conversation->addMessage('ai', $assistantMessage);
    $this->sendReply($account, $contact->wa_id, $assistantMessage);
}
```

#### 3d. Add `formatMenuFallback()` helper

Simple fallback that formats the raw result if LLM returns empty:

```php
protected function formatMenuFallback(string $rawResult, int $page): string
{
    $lines = explode("\n", $rawResult);
    $menuItems = [];
    foreach ($lines as $line) {
        if (str_contains($line, 'Rp')) {
            $menuItems[] = $line;
        }
    }

    $response = "📋 Menu (Halaman {$page}):\n\n";
    $response .= implode("\n", $menuItems);
    $response .= "\n\nMau pesan yang mana? Atau ketik 'menu lainnya' untuk lihat lebih banyak.";

    return $response;
}
```

## Flow Diagram

```
User: "lihat menu"
  → isNextMenuPageIntent? NO
  → isOrderMenuIntent? YES
  → LLM calls get_all_products(page=1)
  → System saves current_menu_page=1
  → User sees 10 products + "Ketik 'menu lainnya' untuk lihat lebih banyak"

User: "ada menu yang lainnya"
  → isNextMenuPageIntent? YES ← deterministic bypass
  → handleNextMenuPage()
    → getCurrentMenuPage() = 1
    → nextPage = 2
    → getAllProducts(page=2)
    → NOT empty → setCurrentMenuPage(2)
    → LLM formats result → send to user
  → User sees next 10 products

User: "masih ada lagi"
  → isNextMenuPageIntent? YES
  → handleNextMenuPage()
    → getCurrentMenuPage() = 2
    → nextPage = 3
    → getAllProducts(page=3)
    → EMPTY → "Sudah tidak ada menu lagi"
```

## Edge Cases

1. **User says "menu lainnya" but has never seen page 1** → `getCurrentMenuPage()` defaults to 1, so page 2 will be shown. This is acceptable because the user likely saw menu before in a prior message.
2. **User says "menu lainnya" when on last page** → `getAllProducts()` returns `EMPTY`, system sends "Sudah tidak ada menu lagi".
3. **Conversation expires** → New conversation starts with `current_menu_page` = default 1.
4. **User says "lihat menu" (fresh request)** → LLM calls `get_all_products(page=1)`, system resets tracking to page 1.
5. **Sliding window removes menu context** → Not a problem because page is stored in `order_context`, not in messages.

### 6. Test File: `tests/Unit/MenuPaginationTest.php` — NEW FILE

One file, minimal tests. Uses `perPage=5` via reflection on the real `getAllProducts()` to keep test data small. 7 tests covering the 3 core goals:

1. **Intent detection** — "menu lainnya" → `NEXT_MENU_PAGE`
2. **Page tracking** — conversation stores/returns current page
3. **Pagination end-to-end** — page 1→2→3→EMPTY with 12 products, perPage=5

```php
<?php

namespace Tests\Unit;

use App\Enums\UserIntent;
use App\Models\AiAgent;
use App\Models\AiAgentConversation;
use App\Models\Category;
use App\Models\Product;
use App\Models\User;
use App\Models\WhatsAppAccount;
use App\Models\WhatsAppContact;
use App\Services\AiAgentService;
use Illuminate\Foundation\Testing\RefreshDatabase;
use Tests\TestCase;

class MenuPaginationTest extends TestCase
{
    use RefreshDatabase;

    protected User $user;
    protected Category $category;
    protected AiAgentConversation $conversation;
    protected AiAgentService $service;

    protected function setUp(): void
    {
        parent::setUp();

        $this->user = User::factory()->create();
        $this->category = Category::factory()->create(['user_id' => $this->user->id, 'is_active' => true]);

        $account = WhatsAppAccount::factory()->create(['user_id' => $this->user->id]);
        $contact = WhatsAppContact::factory()->create(['user_id' => $this->user->id]);
        $aiAgent = AiAgent::factory()->create(['whatsapp_account_id' => $account->id, 'order_enabled' => true]);

        $this->conversation = AiAgentConversation::create([
            'ai_agent_id' => $aiAgent->id,
            'whatsapp_contact_id' => $contact->id,
            'messages' => [],
            'order_context' => [],
            'expires_at' => now()->addHours(24),
        ]);

        $this->service = $this->app->make(AiAgentService::class);
    }

    protected function createProducts(int $count): void
    {
        for ($i = 1; $i <= $count; $i++) {
            Product::factory()->create([
                'user_id' => $this->user->id,
                'category_id' => $this->category->id,
                'name' => "Product {$i}",
                'price' => 10000 + ($i * 1000),
                'is_active' => true,
            ]);
        }
    }

    /**
     * Call protected getAllProducts() via reflection.
     */
    protected function callGetAllProducts(int $page = 1): string
    {
        $method = new \ReflectionMethod($this->service, 'getAllProducts');
        $method->setAccessible(true);

        return $method->invoke($this->service, $this->user->id, false, $page, null);
    }

    // =============================================
    // GOAL 1: Intent detection works
    // =============================================

    public function test_next_menu_page_intent_detected(): void
    {
        $this->assertSame(UserIntent::NEXT_MENU_PAGE, UserIntent::detect('menu lainnya'));
        $this->assertSame(UserIntent::NEXT_MENU_PAGE, UserIntent::detect('lihat lagi'));
        $this->assertSame(UserIntent::NEXT_MENU_PAGE, UserIntent::detect('ada lagi'));
        $this->assertSame(UserIntent::NEXT_MENU_PAGE, UserIntent::detect('masih ada lagi'));
        $this->assertSame(UserIntent::NEXT_MENU_PAGE, UserIntent::detect('lebih banyak'));

        // "lihat menu" should NOT be NEXT_MENU_PAGE
        $this->assertSame(UserIntent::VIEW_MENU, UserIntent::detect('lihat menu'));
    }

    public function test_is_next_menu_page_service_method(): void
    {
        $method = new \ReflectionMethod($this->service, 'isNextMenuPageIntent');
        $method->setAccessible(true);

        // Positive
        $this->assertTrue($method->invoke($this->service, 'menu lainnya'));
        $this->assertTrue($method->invoke($this->service, 'MENU LAINNYA'));
        $this->assertTrue($method->invoke($this->service, 'Lihat Lagi'));

        // Negative
        $this->assertFalse($method->invoke($this->service, 'lihat menu'));
        $this->assertFalse($method->invoke($this->service, 'pesan nasi goreng'));
        $this->assertFalse($method->invoke($this->service, 'halo'));
    }

    // =============================================
    // GOAL 2: Page tracking in conversation
    // =============================================

    public function test_conversation_page_tracking(): void
    {
        // Default is page 1
        $this->assertSame(1, $this->conversation->getCurrentMenuPage());

        // Set and persist
        $this->conversation->setCurrentMenuPage(3);
        $this->conversation->refresh();
        $this->assertSame(3, $this->conversation->getCurrentMenuPage());

        // Clear resets to default
        $this->conversation->clearCurrentMenuPage();
        $this->assertSame(1, $this->conversation->getCurrentMenuPage());

        // Preserves other order_context (cart)
        $this->conversation->updateCart([
            ['product_id' => 1, 'product_name' => 'Test', 'price' => 10000, 'quantity' => 2],
        ]);
        $this->conversation->setCurrentMenuPage(2);
        $this->assertSame(2, $this->conversation->getCurrentMenuPage());
        $this->assertNotEmpty($this->conversation->getCart());
    }

    // =============================================
    // GOAL 3: Pagination returns correct pages (perPage=10)
    // =============================================

    public function test_get_all_products_pagination_flow(): void
    {
        // Create 25 products → 3 pages of 10, 10, 5
        $this->createProducts(25);

        // Page 1: first 10 items
        $result1 = $this->callGetAllProducts(page: 1);
        $this->assertStringNotContainsString('EMPTY', $result1);
        $this->assertStringContainsString('p1/3', $result1);
        $this->assertStringContainsString('get_all_products(page=2)', $result1);

        // Page 2: next 10 items
        $result2 = $this->callGetAllProducts(page: 2);
        $this->assertStringNotContainsString('EMPTY', $result2);
        $this->assertStringContainsString('p2/3', $result2);
        $this->assertStringContainsString('get_all_products(page=3)', $result2);

        // Page 3: last 5 items, no next page hint
        $result3 = $this->callGetAllProducts(page: 3);
        $this->assertStringNotContainsString('EMPTY', $result3);
        $this->assertStringContainsString('p3/3', $result3);
        $this->assertStringNotContainsString('get_all_products(page=4)', $result3);

        // Page 4: empty
        $result4 = $this->callGetAllProducts(page: 4);
        $this->assertStringStartsWith('EMPTY', $result4);
    }

    public function test_get_all_products_small_dataset(): void
    {
        // Edge: exactly 10 products → 1 page
        $this->createProducts(10);
        $result = $this->callGetAllProducts(page: 1);
        $this->assertStringContainsString('p1/1', $result);

        // Edge: 11 products → 2 pages
        Product::factory()->create([
            'user_id' => $this->user->id,
            'category_id' => $this->category->id,
            'name' => 'Extra Product',
            'price' => 50000,
            'is_active' => true,
        ]);
        $result1 = $this->callGetAllProducts(page: 1);
        $result2 = $this->callGetAllProducts(page: 2);
        $this->assertStringContainsString('p1/2', $result1);
        $this->assertStringContainsString('p2/2', $result2);

        // Edge: 0 products → empty
        Product::where('user_id', $this->user->id)->delete();
        $result = $this->callGetAllProducts(page: 1);
        $this->assertStringStartsWith('EMPTY', $result);
    }

    // =============================================
    // GOAL 4: End-to-end simulation with page tracking
    // =============================================

    public function test_full_pagination_flow_with_tracking(): void
    {
        $this->createProducts(25);

        // Step 1: User views menu → page 1
        $result = $this->callGetAllProducts(page: 1);
        $this->assertStringContainsString('p1/3', $result);
        $this->conversation->setCurrentMenuPage(1);

        // Step 2: User says "menu lainnya" → system increments to page 2
        $nextPage = $this->conversation->getCurrentMenuPage() + 1;
        $result = $this->callGetAllProducts(page: $nextPage);
        $this->assertStringContainsString('p2/3', $result);
        $this->conversation->setCurrentMenuPage($nextPage);

        // Step 3: User says "menu lainnya" again → page 3
        $nextPage = $this->conversation->getCurrentMenuPage() + 1;
        $result = $this->callGetAllProducts(page: $nextPage);
        $this->assertStringContainsString('p3/3', $result);
        $this->conversation->setCurrentMenuPage($nextPage);

        // Step 4: User says "menu lainnya" again → EMPTY
        $nextPage = $this->conversation->getCurrentMenuPage() + 1;
        $result = $this->callGetAllProducts(page: $nextPage);
        $this->assertStringStartsWith('EMPTY', $result);
        // Page should stay at 3 (not updated on empty)
        $this->assertSame(3, $this->conversation->getCurrentMenuPage());
    }
}
```

**Note on testing with perPage < 10:** The test above uses the real production `$perPage = 10` via reflection. Since production is `perPage=10`, we need 25 products to create 3 pages. This is fine for SQLite in-memory tests. If you want to test with `perPage=5` specifically, the approach is to create 12 products and verify `p1/3`, `p2/3`, `p3/3`, `EMPTY` — which the `test_full_pagination_flow_with_tracking` test already covers at perPage=10 scale.
